## Required corrections for the approved MVP

- Replace SSO labels with Admin-created password/JWT wording.
- Do not show grounding-confidence or citation-fidelity percentages.
- Do not show processing percentages or estimated remaining time; show named processing stages instead.
- Limit MVP upload messaging to PDF, DOCX, and TXT.
- Keep private sharing within the uploader's department, with Admin access retained and audited.
- Hide saved answers when supporting documents become inaccessible and recheck source access.
- Avoid unverified claims about zero data retention, encryption guarantees, provider regions, model names, or context limits.
- Keep detailed ingestion diagnostics privacy-safe and expose only safe summaries and identifiers.
